Remotion in one idea

A video is a function of the frame number

  • useCurrentFrame() gives 0, 1, 2 …
  • 30 fps: frame 45 is 1.5 seconds
  • No timers, no state
  • Same frame, same picture
// 0 → 1 between frames a and b
export const ramp = (f, a, b) =>
  interpolate(f,
    [a, Math.max(b, a + 1)],
    [0, 1],
    { extrapolateLeft: "clamp",
      extrapolateRight: "clamp" });

Motion basics

Same move, three curves

  • interpolate() maps frames to values
  • An easing changes the feel, not the distance
  • spring() is physics: it overshoots, then settles
Spring

Two numbers decide the feel

  • damping: lower bounces more
  • stiffness: higher is faster
  • A bounce is the curve above the dashed target
spring({ frame, fps,
  config: { damping: 7, stiffness: 220 } })

From a sentence to a word

  • Each word has a start and end frame

Sound

Sound is just another layer

  • The voice: one file per scene, started at its measured frame
  • Effects: made with ffmpeg, each placed on a frame
  • Music: pad and bass, its level is a function of the frame
  • Last step: loudness to −16 LUFS
// low under the voice, up in the gaps
const volume = (f) => {
  let v = 0.75;
  for (const [a, b] of voice)
    v = Math.min(v, interpolate(f,
      [a - 12, a + 6, b - 6, b + 18],
      [0.75, 0.2, 0.2, 0.75]));
  return v;
};
<Audio src={music} volume={volume} />

Working with Claude

Who does what, and what bit us

Claude and you

  • Claude writes scenes, helpers and scripts
  • Claude checks frames as still images
  • You write the script and choose the voice
  • You judge the motion: it cannot watch it

Pitfalls

  • TTS misreads names: respell them for the TTS only
  • A comma pause fools pause detection: use the transcript
  • Pin every remotion and @remotion/* version. 4.0.535 needs zod 4.5.4
  • npx remotion versions tells you when something is off
  • 3D on React 18 needs @react-three/fiber 8.x (9.x asks for React 19)
